Methodology

  • Both systems ingest the same 40 facts about 10 synthetic entities (plus 10 later updates), then answer the same 55 questions (40 known, 15 about attributes never stored).
  • Grading is a deterministic, case-insensitive substring match — not an LLM judge.
  • All entities share one orlog event log and one Mem0 bucket; neither system is told which entity a question is about.
  • orlog runs Anthropic's claude-haiku-4-5 (its own default); Mem0 runs OpenAI's gpt-4o-mini — cross-provider, not same-model. Full reasoning, dataset design, and two real orlog bugs found while building this: benchmarks/vs_mem0/README.md.
